# Notepad2-mod

> *A modified version (fork) of notepad2-mod, itself a modified version (fork) of Notepad2 based on Kai Liu's and other people's patches.*

## Changes compared to the official Notepad2:

* Code folding
* Support for bookmarks
* Option to mark all occurrences of a word
* Word auto-completion
* Syntax highlighting support for AutoHotkey, AutoIt3, AviSynth, Bash, CMake, CoffeeScript,
  Inno Setup, LaTeX, Lua, Markdown, NSIS, Ruby, Tcl, YAML and VHDL scripts
* Improved support for NFO ANSI art
* Support for replacing Windows Notepad using a clean, unintrusive registry-based method
* Other various minor changes and tweaks

## Changes compared to the official notepad2-mod:

* Dark mode support
* Latest version of Scintilla
* Added ability to insert GUID
* Minor bug fixes

## Supported Operating Systems:

* Windows 7, 8, 8.1 and 10 in 32 & 64 bit (not tested)
* Windows 11

## Changed keyboard shortcuts compared to Notepad2:

* <kbd>Ctrl+Alt+F2</kbd>       Expand selection to next match.
* <kbd>Ctrl+Alt+Shift+F2</kbd> Expand selection to previous match.
* <kbd>Ctrl+Shift+Enter</kbd>  New line with toggled auto indent option.
* <kbd>Ctrl+Shift+3</kbd>  Inseert a GUID.

You can use MSVC 2026 to build Notepad2-mod.
